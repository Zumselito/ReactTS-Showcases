# Football app developed with ReactJS/TypeScript (Vite)

A little app to create footballer profiles with ratings stored in your browsers localStorage. **[Deployed with Makefile](https://zumselito.github.io/)**.

## App features

- Functionalities to create, update and delete footballer profiles.

## Programming features

ReactJS

- Routing (react-router-dom)
- Using components
  - Props passing
  - Imports
  - Callbacks
- Applying different hooks
- Applying forms/inputs
- Mapping
- Saving state in browsers localStorage

TypeScript

- Type definition
  - Interfaces
- Interface import

TailwindCSS

- Design Mode (light | dark | system)
- Use of react icons
